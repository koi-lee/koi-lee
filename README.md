## 重点产品：额度星盘 · Quota Orbit

**给经常使用 Codex 的你：了解还剩多少额度、什么时候恢复，以及公开重置消息有什么新进展，方便安排接下来的工作。**

你可以按自己的使用场景选择：

| 你想解决什么 | 从这里开始 |
|---|---|
| 关注公开重置预告、完成消息和原帖依据，少反复翻找消息 | **[网页版 · 直接打开](https://www.starshoreai.com/quota-orbit/)**：免费，无需登录；只展示公开消息，不读取个人额度 |
| 在工作时随手查看自己的剩余额度、恢复时间和本次会话的额度变化 | **[Mac 客户端 · 源码与下载](https://github.com/koi-lee/quota-orbit)**：通过桌宠和菜单栏查看；读取个人额度需在本机安装并登录 Codex CLI |
| 把消息放到桌边或随身的小屏上，抬眼就能看 | **[AI Passport 随身版 · 固件与指南](https://github.com/koi-lee/quota-orbit-aipassport)**：设备连上 Wi-Fi 即可查看公开公告；选装 Mac 同步助手后，还能显示个人额度 |

随身版需要 AI Passport 硬件。个人额度同步还需要 Mac 保持唤醒、登录 Codex、运行同步助手，并与设备处于同一 Wi-Fi；只看公开公告不需要 Mac。

公开重置公告不代表你的个人额度已经恢复。额度星盘帮助你查看信息，不会增加额度或替你执行重置。

## 其他开源工具

- **[KeepAwake](https://github.com/koi-lee/KeepAwake)** — 指定应用运行时，让 Mac 保持唤醒，减少长任务因空闲睡眠中断；也支持手动定时保活。
- **[Koi StyleKit](https://github.com/koi-lee/koi-stylekit)** — 做插画前先选风格、填主题，生成可复用的提示词配方，方便下次沿用；支持网页、CLI 和 Agent Skill。
- **[桌上玩伴 · ToyPal](https://github.com/koi-lee/toypal)** — 把手办照片做成陪在屏幕边的 Codex 桌宠；提供 Agent Skill，当前为预览版，需要图像生成能力。
- **[AI 证件照工作室](https://github.com/koi-lee/ai-id-photo-studio)** — 用 Agent Skill 完成换装、换发型、背景替换与证件照裁剪；正式用途需核对受理要求，不保证证件受理。
- **[WIFI 转发宝串口助手](https://github.com/koi-lee/sms-forwarder-mac)** — 在 Mac 上通过 USB 集中查看适配设备的短信、运行日志与推送结果，方便排查转发问题；当前为预览版。
