### 额度星盘 · Quota Orbit

给使用 Codex 的朋友做的重置消息查看工具：集中查看公开重置预告、完成消息和原帖依据，免费使用，无需登录。

**打开网站 → [www.starshoreai.com/quota-orbit/](https://www.starshoreai.com/quota-orbit/)**

网页展示公开消息，不读取个人账号额度；配套的 [Mac 客户端](https://github.com/koi-lee/quota-orbit) 通过桌宠和菜单栏展示个人额度与恢复时间。

### 开源项目与工具

- **[额度星盘 Mac 客户端](https://github.com/koi-lee/quota-orbit)** — 用 macOS 桌宠和菜单栏查看 Codex 额度、恢复时间与公开重置消息。
- **[KeepAwake](https://github.com/koi-lee/KeepAwake)** — 指定应用运行时阻止 Mac 空闲睡眠，也支持手动定时保活。
- **[Koi StyleKit](https://github.com/koi-lee/koi-stylekit)** — 浏览插画风格、填写主题，生成可复用的提示词配方；支持网页、CLI 和 Agent Skill。
- **[桌上玩伴 · ToyPal](https://github.com/koi-lee/toypal)** — 把手办照片制作成 Codex 桌宠的 Skill；当前为预览版，需要图像生成能力。
- **[AI 证件照工作室](https://github.com/koi-lee/ai-id-photo-studio)** — 换装、换发型、背景替换与证件照裁剪的 Agent Skill；不保证正式证件受理。
- **[WIFI 转发宝串口助手](https://github.com/koi-lee/sms-forwarder-mac)** — 在 Mac 上通过 USB 查看适配设备的短信、运行日志与推送结果；当前为预览版。
